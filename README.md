# MEMORIES ODYSSEY 〜星結びの宇宙飛行士〜

散らばった想いのカケラを集め、星座という名の物語を紡ぐブラウザゲーム。

🎮 **[今すぐ遊ぶ](https://stationaryobserverno043.github.io/memories_odyssey/)**

---

## ゲーム概要

ファミコン風のピクセルアートで描かれた宇宙を舞台に、
宇宙飛行士が星のカケラを集めて星座を完成させていくアドベンチャーゲーム。

---

## 主な機能

- ピクセルアートスタイルのブラウザゲーム（スマホ対応）
- タイムワープ機能（過去のLAPに戻って探索）
- 星座収集システム
- PWA対応（ホーム画面に追加可能）

---

## 使用技術

- HTML / CSS / JavaScript（単一ファイル構成）
- Google Fonts（Press Start 2P / Noto Sans JP）
